DEPLOYMENT CONFIGURATION

Settings & setup

Configure the server-side connection from Render to your n8n instance.

n8n webhook connection

Set these environment variables in your Render web service.
N8N_WEBHOOK_URL

Your production webhook URL. Example path:

https://YOUR-N8N-HOST/webhook/pdf-lead-intake
N8N_AUTH_HEADER_NAME (optional)

Header name if your webhook is protected by a header credential, for example a custom authentication header.

N8N_AUTH_HEADER_VALUE (optional)

Secret value for that header. Store it only in Render environment variables, never in frontend code.

MAX_FILE_MB

Maximum accepted PDF size. Default is 15 MB.
